# config/

| קובץ | מה בו |
|---|---|
| `waivers.json` | ויתורים: על איזה חוק, על אילו תוצאות, נימוק, בעלים ותאריך תפוגה |
| `copies.json` | הקבצים בריפו שהם עותק של קובץ אחר, ומקור כל אחד, כדי שעותק שנשאר מאחור יתגלה |

ויתור נכתב ביד, ב-PR, ורק על חוק שמותר לוותר עליו (`waivable`). אורכו לכל היותר
`max_waiver_days` של הקטלוג. ויתור שפג אינו מוותר עוד: התוצאה חוסמת ומדווחת `expired`.
