# qa-master/

התיקייה של QA Master בריפו הזה. המבנה שלה קבוע, כי הקטלוג המשותף מוצא כל קובץ לפי
מקומו: שינוי מבנה הוא גרסת קטלוג שוברת, עם רשימת ה-`git mv` שלה (החלטה 005).

| נתיב | מה בו | מי כותב |
|---|---|---|
| `profile.json` | מה הפרויקט. ממנו נגזר אילו חוקים חלים | אדם, ב-PR · `fetch_profile.py` מציע |
| `config/` | ויתורים, ורשימת העותקים | אדם, ב-PR |
| `db/` | מה שנבדק מול המסד | אדם, ב-PR |
| `integrations/` | החיבורים למערכות חיצוניות | אדם, ב-PR |
| `workflows/` | בדיקות על קובצי האוטומציה | אדם, ב-PR |
| `edge-functions/` | בדיקות על פונקציות הקצה | אדם, ב-PR |
| `generated/` | המנוע בגרסה המוצמדת, וקובץ הנעילה | `sync` ו-`resolve` בלבד |
| `AGENTS.md` | שכבת הסוכן, נגזרת מסט החוקים | `qa_master.py agent` |

**שום דבר תחת `generated/` אינו נערך ביד** (החלטה 009). כל קובץ שם ניתן לשחזור בייט
לבייט, ו-CI משווה אותו להרצה טרייה.

המסמכים לאנשים על QA Master בפרויקט הזה נמצאים ב-`docs/qa-master/`.
