# db/

מה שנבדק מול המסד.

| נתיב | מה בו |
|---|---|
| `contract.json` | חוזה הסכמה: מה הקוד מצפה למצוא במסד |
| `rules/` | החוקים העסקיים של הפרויקט, ב-SQL |
| `harness/` | הכנת המסד לפני שהחוקים רצים, במה שייחודי לפרויקט |
| `seed/` | הנתונים שהבדיקות רצות עליהם |
| `gates/` | שערים, וב-`gates/break/` מה שאמור להכשיל כל אחד |
| `operations/` | הפעולות שחייבות לעבוד |
